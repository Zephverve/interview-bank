学习建议

如果你是完全的小白（建议顺序）

  01-基础概念 → 09-Prompt工程 → 03-RAG技术 → 04-工具调用
  → 02-核心框架 → 05-记忆系统 → 06-多智能体
  → 07-大模型基础 → 08-工程化实践

如果你有一定基础（按优先级）
  02-核心框架（ReAct 必考） → 03-RAG技术（高频）
  → 04-工具调用（MCP 热点） → 08-工程化实践（企业级加分）
  → 其余模块查漏补缺
