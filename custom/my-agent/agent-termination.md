**题目**：Agent 的循环怎么终止？怎么防止无限循环？

### 回答

四道闸门，缺一不可。

1. **硬性步数上限**：最大迭代轮数（经验值 15-25 轮）。
2. **Token 预算上限**：累计 Token 超阈值强制收尾。
3. **完成判定（DoD, Definition of Done）**：任务开始时就把验收标准结构化，每轮结束检查是否满足，满足即停。
4. **无进展检测**：连续 N 轮工具调用返回高度相似的结果 / 同一个工具被反复调用 → 判定卡死，强制终止并向上报错。

**追问预判**：
- 「连续 N 轮怎么判断'高度相似'？」→ 简单做法是工具+参数的哈希去重；更稳的是把最近几轮的 action 向量化算相似度。
- 「终止后怎么给用户交付？」→ 不能空手返回，把已完成的部分 + 卡住的位置 + 建议人工介入的点整理成结构化报告。
