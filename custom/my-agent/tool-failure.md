**题目**：工具调用失败了怎么办？

### 回答

三层处理。

| 层 | 处理 | 适用 |
|---|---|---|
| **参数层** | 把错误信息回灌给模型，让它修正参数重试（最多 1-2 次） | 参数格式错、缺字段 |
| **调用层** | 指数退避重试 | 网络超时、限流 |
| **业务层** | 换工具 / 换策略 / 降级 | 接口本身不可用、无权限 |

- **关键原则**：**错误信息必须以结构化形式回灌给模型**（错误码 + 原因 + 建议），而不是抛异常中断。Agent 的鲁棒性很大程度上取决于它能不能读懂错误并自我修正。
- **不能重试的情况**：非幂等操作（已下单、已发送）**绝不能自动重试**，必须人工确认或先查状态。
