**题目**：Token 成本怎么优化？

### 回答

五个手段，按收益排序。
1. **上下文压缩**（收益最大）：长周期任务上下文是成本主因。
2. **Prompt Cache**：稳定前缀缓存，成本降一个数量级。
3. **模型分级路由**：简单任务（分类、抽取、门控）用便宜的小模型，复杂推理才用大模型。
4. **工具输出裁剪**：工具返回的大 JSON 只取需要的字段，不要把整个响应塞进上下文。
5. **减少不必要的多 Agent**：每个 SubAgent 都是一份独立的上下文成本。
