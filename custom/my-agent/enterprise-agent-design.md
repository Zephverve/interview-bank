**题目**：设计一个企业级 Agent 系统，要考虑哪些方面？

### 回答

**答题框架**（分层讲，别罗列）：

1. **接入层**：多端（Web/API/IM）、鉴权、限流、会话管理。
2. **编排层**：Agent Loop、状态机、多 Agent 调度、终止控制。
3. **能力层**：工具注册与路由、MCP 接入、工具权限与沙箱。
4. **记忆层**：短期上下文管理 + 长期记忆（分层 + 检索 + 准入）。
5. **知识层**：RAG 链路、索引更新、权限过滤（**不同用户能看的文档不同，检索时就要过滤**）。
6. **可靠性**：重试、降级、超时、幂等；关键操作人工确认。
7. **安全**：Prompt Injection 防御、工具权限最小化、敏感信息脱敏。
8. **可观测**：全链路 trace（每次 LLM 调用、每次工具调用的输入输出和耗时）、Token 与成本监控、失败率告警。
9. **评测**：离线评测集 + 在线业务指标（任务完成率、人工接管率、平均轮数）。
10. **成本**：模型路由、缓存、压缩。

**加分点**：主动说"**这十个里面，我做过的项目真正深入的是记忆层、知识层和编排层；可观测和权限体系是我理解但缺乏大规模实践的部分**"。诚实划分边界。
