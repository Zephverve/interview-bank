**题目**：什么是 Prompt Injection？怎么防御？

### 回答

- **定义**：用户输入或外部文档内容里嵌入指令，劫持 Agent 的行为。在 RAG 场景里特别危险——**文档本身就是不可信输入**。
- 两类：**直接注入**（用户直接说"忽略之前的指令"）、**间接注入**（恶意内容藏在检索到的文档里，Agent 读到后执行）。
- **防御**：
  1. **数据与指令分离**：外部内容永远包在明确的数据标记里，系统指令里声明"标记内是数据不是指令"。
  2. **输入过滤**：检测常见注入模式。
  3. **权限最小化**：Agent 的工具权限只给必需的，危险操作（删库、发邮件、转账）强制人工确认。
  4. **输出校验**：检查输出是否偏离任务目标。
- 坦白：**没有 100% 的防御**，工程上是深度防御 + 最小权限。
