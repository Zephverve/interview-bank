**题目**：你的反问

### 回答

按面试官层级选问：
- **问一面工程师**：团队现在 Agent 系统最大的技术痛点是哪一块？是召回质量、成本、还是稳定性？
- **问二面组长**：团队怎么衡量 Agent 系统的效果？离线评测和线上指标各占多少权重？
- **问三面负责人**：这个岗位半年内最重要的一件交付是什么？团队在 Agent 方向是自研还是以集成开源为主？
- **通用好问题**：你们在做 Agent 的时候，怎么平衡"自己写框架"和"用开源框架"？

**别问**：加班多不多、能不能远程、涨薪幅度（HR 环节再问）。
