**题目**：为什么从 CV / 时序转向大模型 Agent？

### 回答

不要贬低过去，要讲清**能力迁移**。
- **真实的迁移逻辑**：我的研究是 GCN+Transformer 双流建模，本质是**结构化的信息融合与序列决策**；Agent 系统里多路召回融合、多 Agent 信息汇聚，是同一类问题的不同载体。我对"系统怎么组织信息、怎么决策"这件事的兴趣是一致的。
- **为什么转**：大模型 Agent 是当前**工程问题密度最高**的方向——检索、记忆、编排、评测、成本，每个都是开放性工程问题，适合我这种喜欢抠细节的人。
- **诚实的一句**："CV 那边我做到发论文的程度，但我判断自己的长期兴趣在 Agent 系统方向。**这个转向不是逃离，是选择。**"
