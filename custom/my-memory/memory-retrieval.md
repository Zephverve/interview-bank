**题目**：记忆检索不能只讲 Top-K，怎么做到召回准又不污染上下文？

### 回答

- **准**：多路召回（语义 + 关键词 + 时序）+ 重排，而不是单路 Top-K。
- **不污染**：三个机制。
  1. **准入过滤**：相关性阈值 + 时效性 + 置信度三重过滤，宁缺毋滥。
  2. **分层注入**：高置信记忆直接进 system prompt，中等置信的作为"参考信息"附带，低置信不注入。
  3. **预算控制**：给记忆注入设 Token 上限，超出按分数截断。
- 一句话总结我的观点：**记忆系统的价值不在于"记得多"，而在于"检索时能不被打扰"**。召回率不是越高越好，注入的每一条都在挤占注意力。
