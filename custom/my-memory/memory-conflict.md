**题目**：新旧记忆冲突怎么处理？用户要求删除怎么办？

### 回答

- **冲突处理**：不能简单覆盖（可能误删），也不能共存（检索时自相矛盾）。通用做法是**保留版本 + 时间戳**，检索时按时间优先返回最新，并在上下文中标注"该信息于 X 时间被更新"。
> ⚠️ **你的实习里 Graphiti 的双时态是现成能力，但"你怎么用它对冲突"是你的设计** —— 这题要按你的实际情况答。
- **Graphiti 的双时态建模**（你的实习正好做了这个，**必须讲**）：
  - `valid_time`：这个事实在**现实世界里**成立的时间区间。
  - `ingestion_time`：这个事实**被系统写入**的时间点。
  - 意义：既回答"当时是什么情况"，也回答"我当时知道什么"。例如用户 3 月改了偏好，系统 5 月才录入，这两个时间不是一回事。做审计和回溯时缺一不可。
- **删除**：软删除（标记 invalid_at）+ 向量库同步删除 + 关联边失效。不能只删向量，否则图谱里会留下悬空的实体。

**追问预判**：
- 「为什么不直接硬删？」→ 硬删会破坏因果链，导致后续推理缺依据；且审计场景需要留痕。合规场景（用户行使删除权）才做硬删。
