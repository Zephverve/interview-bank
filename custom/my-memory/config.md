**题目**：为什么要单独抽一个 Config 层？

### 回答

因为**不同引擎调用 LLM 的时机和方式完全不同**，这是接入过程中最容易被低估的复杂度。

Graphiti 在抽取实体和关系的时候要调 LLM，它对输出格式有严格要求；LightRAG 在查询改写和图谱构建的时候调 LLM；Mem0 在总结对话、抽取用户偏好时调 LLM；各家对 Embedding 模型的使用方式也不一样。

如果每个引擎各自配一套密钥和参数，会出两个问题：一是**无法公平对比** —— 你可能在做评测时发现 A 引擎比 B 引擎好，实际上只是因为 A 用了更强的模型；二是**配置爆炸**，四个引擎乘上多个环境，配置管理会失控。

Config 层的职责就是统一注入同一套 LLM 和 Embedding 配置，让所有引擎在**同等条件下**运行。这不只是工程整洁问题，它是评测结论可信的前提。
