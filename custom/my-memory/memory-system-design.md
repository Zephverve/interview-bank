**题目**：Agent 的记忆系统怎么设计？短期和长期记忆怎么配合？

### 回答

- **短期记忆**：当前任务的上下文窗口内容。特点：快、易失、容量受窗口限制。管理手段是滑动窗口 + 摘要压缩。
- **长期记忆**：跨任务持久化。按内容分四类：**语义记忆**（事实知识）、**情景记忆**（做过什么）、**程序记忆**（技能/SOP）、**用户画像**（偏好）。
- **配合方式**：任务开始时按当前 query 检索长期记忆注入上下文 → 任务结束时把本次产生的可复用内容写回长期记忆。这就是一个**读写闭环**。
- 你的 EvoAgent 就是这个模型的具体实现（L0-L4）。

**追问预判**：
- 「检索长期记忆也会污染上下文吧？」→ 会。所以第一道闸门是**准入**：只注入和当前任务相关性超过阈值、且非过期的记忆；第二道是**压缩**：命中的记忆先摘要成单行再注入。
