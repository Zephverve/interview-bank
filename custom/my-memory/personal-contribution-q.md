**题目**：三个月实习做这么多东西，哪些是你真正做的？

### 回答

主动划清边界，比被戳穿好得多。

- **明确是我做的**：Adapter / Router / Config 分层架构设计与实现、统一 API 定义、四引擎的接口适配与配置统一、多存储编排、评测流程搭建与跑通、Docker Compose 部署、pytest 测试体系。
- **不是我做的**：四个记忆引擎本身**不是我开发的**，我用的是开源实现；底层算法（Graphiti 的双时态、LightRAG 的图检索）是理解并适配，不是原创。
- **一句话定位**："我这段实习的核心价值是**把四个异构的开源记忆系统，做成一个可对比、可替换、可评测的统一记忆运行时**，并且用统一的基准回答了'什么样的任务该选哪个引擎'这个问题。"

这个答法既诚实又展示了你对自身价值的清醒认知，面试官反而会加分。
