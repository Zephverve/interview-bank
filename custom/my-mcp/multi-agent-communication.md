**题目**：多 Agent 有哪几种通信模式？怎么选？

### 回答

| 模式 | 机制 | 优势 | 劣势 | 代表 |
|---|---|---|---|---|
| **消息传递** | Agent 间显式收发消息 | 松耦合、可分布式部署 | 通信开销大、调试复杂 | AutoGen Actor、A2A |
| **共享状态** | Agent 读写同一 state | 一致性强、易聚合、有全局视图 | 并发写冲突（需 Reducer）、耦合度高 | LangGraph State |
| **黑板模式** | Agent 读写共享"黑板"上的部分解 | 知识源解耦、触发式协作 | 结构松散、难调试 | 经典 AI 架构 |

- **选择依据**：需要动态协商、Agent 可能不在同一进程 → 消息传递；需要全局视图、流程确定 → 共享状态；多专家机会主义式协作 → 黑板。
- **诚实补充**："黑板模式和共享内存模式在实践中界限很模糊，很多时候共享状态就是黑板的一种实现。"
