**题目**：把繁重操作委托给 SubAgent 保持主 Agent 上下文干净，信息怎么回来？

### 回答

**只回传结构化结论，不回传执行过程。**

具体说，SubAgent 执行完一个子任务后，回传的是类似「做了什么、结论是什么、产出的文件或数据在哪、有没有异常」这样的结构化字段。它探索过程中的几十轮工具调用、报错、重试，**都不进主 Agent 的上下文**。

这是上下文隔离的核心价值。如果不隔离，主 Agent 的上下文会被子任务的执行细节迅速填满，既挤占了它做决策的"注意力预算"，又推高了 Token 成本。委托的本质不是"分担工作"，而是**分担上下文压力**。
