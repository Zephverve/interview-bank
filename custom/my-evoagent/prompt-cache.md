**题目**：Prompt Cache 怎么用？什么时候失效？

### 回答

Anthropic 的缓存是**显式标记**的 —— 需要把稳定不变的部分（system prompt、长文档等）放在请求前缀并打上缓存标记，变化的部分放在后面。命中缓存的部分 Token 成本能降一个数量级，延迟也明显下降。

**失效条件有两个**：一是**前缀一变就全部失效**，所以前缀里不能放任何动态内容（比如时间戳、会话 ID，这类东西要挪到后面）；二是**缓存有 TTL**，Anthropic 的缓存有效期是分钟级，超过就重新计算。

这个特性决定了 Prompt 的结构设计：**稳定内容前置、动态内容后置**。这既是为了缓存，也符合注意力机制对长上下文的一般规律。
