**题目**：多 Agent 的"幻觉放大"怎么处理？

### 回答

- 机制：Agent A 编造一个事实，Agent B 采信并基于它继续推理，最后变成"共识"，因为**没有任何一个环节在做事实核查**。
- 治理：
  1. **信息溯源**：所有跨 Agent 传递的事实必须带来源引用（哪个工具返回的、哪个文件里的）。
  2. **关键节点强制核验**：涉及最终结论的事实，必须由独立验证环节回到原始数据核对，不能采信上游转述。
  3. **共享状态只写已验证内容**：Agent 之间的共享 memory 只接受带证据的写入，未经验证的推断标为"假设"而不是"事实"，且不能作为下游的前提。
  4. **减少不必要的多 Agent**——这是最根本的。**能单 Agent 就别多 Agent**，多 Agent 每多一跳就多一次幻觉放大机会。
