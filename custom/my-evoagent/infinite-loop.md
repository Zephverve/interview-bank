**题目**：多 Agent 之间怎么防止死循环 / 互相指使？

### 回答

- 根因是**没有明确的收敛标准 + 缺少全局状态**。三个机制：
  1. **全局单调计数器**：全局最大轮数，所有 Agent 共享，不是每个 Agent 各算各的（否则两个 Agent 各跑 10 轮就是 20 轮）。
  2. **任务所有权（Ownership）**：每轮对话必须有明确的"当前负责人"，只有负责人有权发起下一跳；收到非负责人请求时不响应，直接回退给负责人。
  3. **DoD 结构化前置**：任务下发时必须带验收标准，子 Agent 完成即上报，主 Agent 判定通过就终止，不给"再优化一下"的空间。
- 补充：**A2A 调用链深度限制**——A 调 B，B 再调 C，深度超过 2 层直接拒绝，这是最有效的兜底（多 Agent 扯皮通常发生在深层递归里）。
