**题目**：下次任务怎么自动加载历史技能？怎么判断该加载哪些？

### 回答

> ⚠️ 下面的"查询归一化 + 三档阈值"是**通用做法**，你的实现可能不同。

**通用做法**：用**任务意图的向量相似度检索**，但有个容易踩的坑 —— **不能拿用户的原始 query 直接去匹配**。

原始 query 说"帮我分析一下这个数据"，技能库里存的是"数据文件的批量清洗与统计流程"，字面差异很大，直接算相似度会漏检。所以需要先用 LLM 把 query **归一化成结构化表示**（任务意图 + 关键实体 + 操作类型）再检索。

命中后按置信度分档：高置信直接加载、中间区间加载但标注"需验证适配性"、低置信不加载。分档的意义是避免误匹配的负面引导 —— 加载一个不相关的技能，可能比不加载更糟。

**你要补充的**：你的实际检索方式是什么？阈值是单一阈值还是分档？加载后以什么形式注入（few-shot / 步骤模板 / 系统提示）？
