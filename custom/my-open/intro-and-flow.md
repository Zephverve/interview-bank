**题目**：面试流程与自我介绍怎么组织？

### 回答

面试流程是：**自我介绍 → 项目介绍 → 技术深挖 → 反问**。

关键认知：**技术问题几乎全部从"项目介绍"里长出来** —— 你怎么介绍项目，直接决定后面被问什么。所以开场那三分钟不能随口讲。

**自我介绍的结构（控制在 90 秒内）**：

1. **一句话定位（10s）**：学校专业 + 研究方向 + 目标岗位。
2. **硬指标（10s）**：排名 9/51、CET-6、蓝桥杯 C++ 省二等奖三次。
3. **项目主线（60s）**：按「Agent 工程 → RAG 落地 → 算法底座」串成一条线，不要平铺罗列。
4. **收尾落点（10s）**：一句话说清"我为什么投这个岗位"。

**项目介绍的结构（每个项目 60—90 秒）**：

1. **一句话背景**：做什么、给谁用、解决什么问题。
2. **我的角色**：独立做还是团队几人、负责哪块 —— **这段必须诚实**。
3. **技术架构**：分层说，先骨架后细节。
4. **量化结果**：给关键指标，且**指标必须能拆**。
5. **一个真实难点**：按"现象 → 定位 → 根因 → 修法 → 效果"讲。

**一个实用技巧：主动埋伏钩子**。项目介绍时主动抛出你最想被问的那个技术点。比如讲 EvoAgent 时特意提一句"记忆我故意没用向量库，而是做了文件化的分层" —— 面试官大概率会顺着问，战场就被拉到了你准备最充分的地方。

**注意**：面试时用第一人称直接讲你的技术积累和项目事实，报简历上的数字口径，不要出现"我参考的某份材料说"这类表述。
