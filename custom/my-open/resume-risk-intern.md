**题目**：简历上三个月实习会怎么被追问？

### 回答

**面试官会问**：三个月做这么多引擎接入，是真实产出还是包装？

**怎么答**：**主动划清边界**。这个项目是我**独立做的** —— 架构设计到代码实现到评测一个人完成。但"独立做"不等于"从零造引擎"：四个记忆引擎本体是开源实现，我用的是它们的官方 SDK，**核心算法不是我的**；统一运行时层（Adapter / Router / Config / API / CLI / 前端 / 评测套件）是我写的。

**这么讲有两个好处**：一是显得懂工程（知道什么时候不该重复造轮子），二是把追问引到你的主场 —— "你怎么统一封装的"。
