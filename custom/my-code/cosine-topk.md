**题目**：手写余弦相似度 + Top-K 检索

### 回答

**题目**：给定一个 query 向量和 N 个候选向量，返回最相似的 Top-K。

**考察点**：
- 余弦相似度的计算（点积 / 模长乘积），以及**归一化后点积等价于余弦**这个优化。
- Top-K 的两种实现：全排序（`np.argsort`，简单）vs 堆（`heapq.nlargest`，K 远小于 N 时更优）。**能说出什么时候用哪个是加分项**。
- 边界：K 大于 N、零向量、空输入。
