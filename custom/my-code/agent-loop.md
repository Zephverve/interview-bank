**题目**：手写 Agent Loop + 工具调用解析

### 回答

**题目**：不用任何 Agent 框架，手写一个 ReAct 风格的 Agent 循环。

**考察点**（面试官真正想看的）：
1. **循环结构**：LLM 输出 → 解析 Action（工具名 + 参数）→ 执行工具 → 结果回填 Observation → 判断是否终止。
2. **终止条件**：模型输出 Final Answer 即结束 —— **必须同时有最大轮次兜底**。
3. **解析容错**：模型输出格式不合法时怎么办（重试 / 降级 / 报错回灌）。
4. **错误信息回灌**：工具执行失败要把错误**结构化地**喂回模型让它自纠，而不是抛异常中断。
5. **上下文组装**：每一轮把历史 Action/Observation 拼进 prompt 的方式。

**为什么这题对你性价比最高**：这是你 LangGraph 项目的底层原理。面试官问"不用 LangGraph 你怎么写"的概率很高，而且你可以**边写边讲你项目里的对应设计**（终止条件、错误回灌、上下文压缩），把一道代码题变成项目展示。
